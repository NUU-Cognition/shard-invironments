# Map

A Map is a named, navigable collection of notes — the unit of organization for a Flint's semantic content. It is realized as a folder whose root file, the *index*, declares the collection's Information Environment and a higher-level navigation guide, while the notes themselves live alongside it. A Map exists to make a body of related models walkable: it turns a pile of notes into a curated entry point a mind can enter and disclose progressively. Reach for a Map when you have understanding to organize and navigate; reach for a work artifact (Task, Plan) when you have something to *do* rather than something to *know*.
